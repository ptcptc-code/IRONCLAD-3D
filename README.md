# IRONCLAD — 3D 机甲整备与战斗模拟器

推荐直接使用 Chrome 或 Edge 打开 IRONCLAD-3D.html；这是单文件离线版，可以单独复制或分享。index.html 为同功能的多文件开发入口。运行不需要服务器、账号或联网；需要浏览器支持 WebGL 2 并启用硬件加速。

## 操作

- 拖动空白场景旋转镜头，滚轮或双指缩放，右键拖动平移。
- 左侧选择躯干、头部、手臂、腿部和武器，每类 3 种独立 3D 造型。
- 涂装、外形和性能参数实时更新，配置自动保存在当前浏览器。
- “部件特写”跟随当前选中的部件类别；“机体全景”或 R 键恢复镜头。
- “机库全景”查看环境；“自动环绕”绕机甲旋转。
- “沉浸模式”或 H 键隐藏界面，Escape 返回；“保存场景截图”导出纯场景 PNG。
- 右上角切换电影级、均衡、流畅画质。低性能设备建议使用流畅模式。
- 战斗模拟时锁定配置，播放双机交火、武器特效、命中火花与倒地。火力影响伤害，装甲减伤，机动影响先手与闪避，同步率影响暴击；最多 12 回合。
- “导出当前机甲”保存已定制机甲的 GLB 模型。

## 文件

- IRONCLAD-3D.html：单文件启动入口，包含运行所需的全部样式和代码。
- index.html：多文件开发入口。
- app.js：部件配置、存档与战斗计算。
- styles.css / scene.css：界面和响应式布局。
- scene.bundle.js：包含 Three.js 的本地渲染程序，已构建，可直接运行。
- src/assets.js：程序化 PBR 表面、几何与绘制辅助。
- src/mech.js：分层装甲、关节、背包和各类可替换机甲模块。
- src/hangar.js：检修平台、工业机库、管线、机械臂、标识及光束。
- src/scene.js：环境光照、阴影、环境遮蔽、辉光、镜头及战斗特效。
- assets/IRONCLAD-MECH.glb：默认机甲模型，包含材质与贴图。
- assets/IRONCLAD-HANGAR.glb：机库与默认机甲的完整场景模型，包含材质与贴图。

GLB 为静态模型资产，支持导入 Blender 或其他兼容 glTF 2.0 的软件。网页镜头、战斗行为、粒子、后处理及运行时灯光不包含在静态模型中，需要在目标软件内重新配置。

分享 IRONCLAD-3D.html 时只需要这一个文件；分享 index.html 版本时，请保持入口、两个 CSS、app.js 和 scene.bundle.js 在同一目录。assets 目录供模型导入，不是网页运行必需项。

## 美术范围

这是以高品质科幻机库为方向的浏览器实时美术原型：程序化硬表面建模、倒角装甲、金属度与粗糙度材质、磨损纹理、冷暖灯光、软阴影、SSAO、辉光和光束雾效果。并非已经通过商业 3A 项目完整制作与验收流程的最终资产包；没有手工高模烘焙、多级 LOD、角色骨骼蒙皮或完整战斗动作库。

## 修改与构建

已安装 Node.js 时，在本目录执行：

```sh
npm ci
npm run build
```

更改 src 下的文件后重新构建；直接使用不需要安装 Node.js。Three.js 与构建依赖已锁定版本。
